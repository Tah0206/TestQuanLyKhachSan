# Giới thiệu

Đây là repository chứa các **Automated Test** được xây dựng cho dự án **Hotel Management System**.

Mục tiêu của dự án là đảm bảo các chức năng trong hệ thống hoạt động chính xác, ổn định và hạn chế lỗi phát sinh trong quá trình phát triển.

Repository này **không phải hệ thống quản lý khách sạn**, mà chỉ chứa mã nguồn phục vụ cho việc kiểm thử tự động.

# Hướng dẫn sử dụng

Clone repository

```bash
git clone https://github.com/Tah0206/TestQuanLyKhachSan.git
```

Mở project bằng Visual Studio.

Restore NuGet Packages.

Build project.

Chạy toàn bộ test bằng:

```
Test Explorer
```

hoặc

```
Ctrl + R, A
```
